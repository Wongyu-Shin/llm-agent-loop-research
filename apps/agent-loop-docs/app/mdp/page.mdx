  <Section id="checkpoint" title="MDP state에는 다음 행동을 고르는 데 필요한 작업 정보를 담습니다">
    MDP를 적용하려면 의사결정에 필요한 정보를 state에 담아야 합니다. 결제 API 사례를 다음 TypeScript 타입으로 적어 봅니다.

    ```ts
    type WorkState = {
      failureReproduced: boolean
      contractRead: boolean
      patchApplied: boolean
      unitTestsPassing: boolean
      contractTestsPassing: boolean
    }

    type Action = "inspect-contract" | "apply-patch" | "run-tests"
    ```

    이 실습은 결제 API 작업을 네 state로 줄였습니다. `Bellman 1회`를 누르면 현재 value를 이용해 각 action의 expected return을 계산하고, 가장 큰 값을 새 state value로 저장합니다. discount factor $\gamma$가 커질수록 당장 드는 조사 비용보다 이후의 회귀 위험과 성공 보상이 더 크게 반영됩니다.

    <LeadStatement>
      이 실습에서 중요한 것은 반복 횟수가 아닙니다. 서로 다른 action의 transition과 장기 결과를 비교하는 일입니다.
    </LeadStatement>

  <Section id="markov" title="현재 state만으로 다음 전이를 예측할 수 있어야 Markov 조건을 만족합니다">
    Markov property는 과거를 버리라는 규칙이 아닙니다. 더 오래된 history 없이도 현재 state만으로 다음 state의 분포를 계산할 수 있다고 가정합니다.

    $$
    P(S_{t+1}=s'\mid S_0,A_0,\ldots,S_t=s,A_t=a)
    = P(S_{t+1}=s'\mid S_t=s,A_t=a)
    $$

    예를 들어 `contractTestsPassing: false`만 기록하고 어떤 입력에서 왜 실패했는지 지워 버리면 state가 부족할 수 있습니다. 같은 boolean state라도 실패 입력에 따라 다음 patch가 달라지기 때문입니다. history를 state에 더 넣거나, 실제 state를 직접 볼 수 없다고 보고 POMDP로 넘어가야 합니다.
  </Section>

  <Section id="formal-model" title="결제 API 작업을 MDP 요소와 Bellman 식으로 표현합니다">
    유한 MDP는 보통 $\langle S,A,P,R,\gamma\rangle$로 적습니다.

    <TermGrid
      items={[
        { symbol: "S", term: "State space", description: "의사결정에 필요한 작업 상태의 집합" },
        { symbol: "A", term: "Action space", description: "agent가 고를 수 있는 도구 호출과 변경 작업" },
        { symbol: "P", term: "Transition model", description: "P(s'|s,a), action 뒤 다음 state의 확률" },
        { symbol: "R", term: "Reward model", description: "성공, 비용, 지연, 위험을 반영한 즉시 평가" },
        { symbol: "γ", term: "Discount factor", description: "0 이상 1 미만, 미래 결과를 현재 선택에 반영하는 비율" },
      ]}
    />

    정책 $\pi(a\mid s)$를 따를 때 state value는 discounted return의 기댓값입니다.

    $$
    V^\pi(s)=\mathbb{E}_\pi\left[\sum_{k=0}^{\infty}\gamma^k R_{t+k+1}\mid S_t=s\right]
    $$

    최적 value는 Bellman optimality equation으로 적을 수 있습니다.

    $$
    V^*(s)=\max_a\sum_{s'}P(s'\mid s,a)\left[R(s,a,s')+\gamma V^*(s')\right]
    $$

    <Note label="MDP와 동적계획법" tone="neutral">
      <p>MDP는 문제 모형입니다. Value iteration과 policy iteration은 transition과 reward model이 주어졌을 때 policy를 구하는 해법입니다. `observe → act → observe`를 반복한다는 이유만으로 agent가 동적계획법을 수행한다고 부를 수는 없습니다.</p>
    </Note>
  </Section>
