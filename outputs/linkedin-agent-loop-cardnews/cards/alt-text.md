# LinkedIn Card News Alt Text

## Card 01

LLM agent loop의 핵심 질문을 “무엇이 loop를 닫는가?”로 재정의하는 첫 카드.

## Card 02

LLM agent loop가 모든 작업의 필수 구조가 아니라 objective mismatch가 큰 작업에서 생기는 조건부 구조라는 카드.

## Card 03

next-token, sequence likelihood, task utility가 서로 다른 목적함수임을 보여주는 카드.

## Card 04

장기 LLM agent 작업이 단순 텍스트 생성에서 폐루프 시스템 문제로 바뀌는 카드.

## Card 05

작은 파일럿에서 단순 반복만으로는 성능 개선을 보장하지 못했다는 카드.

## Card 06

verifier의 독립성, calibration, task utility 정렬이 중요하다는 카드.

## Card 07

단순 실패 판정보다 수리 가능한 diagnostic feedback이 중요하다는 카드.

## Card 08

tool access가 LLM의 내부 추측을 외부 관측으로 검증하게 만든다는 카드.

## Card 09

state ownership, provenance, rollback, stopping rule이 agent loop에 필요하다는 카드.

## Card 10

좋은 LLM agent loop는 더 오래 말하는 것이 아니라 더 좋은 신호로 행동을 바꾸는 시스템이라는 결론 카드.
